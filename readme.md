## 📋 Descripción

Sitio web educativo con calculadoras estadísticas especializadas para análisis de datos. Incluye herramientas para datos cualitativos, cuantitativos discretos y continuos, con generación automática de tablas de frecuencia y visualización gráfica.

## ✨ Características Principales

### 📈 **Datos Cualitativos**
- Distribución de frecuencia por categorías
- Gráficos de barras y circulares
- Ordenamiento por frecuencia
- Tablas de frecuencia absoluta y relativa

### 📊 **Datos Cuantitativos**
- **Discretos**: Frecuencia por valores específicos
- **Continuos**: Intervalos automáticos/manuales
- Histogramas, ojivas y polígonos de frecuencia
- Cálculo automático de marcas de clase

### 🎨 **Interfaz**
- Diseño moderno con fondo animado
- Paleta de colores verde-azul tecnológica
- Responsive (mobile-first)
- Iconos Font Awesome
- Transiciones y efectos visuales

## 🚀 Demostración

### Acceso Rápido
1. **Página Principal**: Selección de calculadoras
2. **Datos Cualitativos**: Análisis por categorías
3. **Datos Cuantitativos**: Análisis numérico (discretos/continuos)

## 🔧 Instalación y Uso

1. **Clonar repositorio**
   ```bash
   git clone https://github.com/EdwinSotoSHz/Calculadora-de-Distribucion-de-Frecuencias.git
   ```

2. **Abrir en navegador**
   - Abrir `index.html` directamente
   - O usar servidor local (Live Server, Python HTTP, etc.)

3. **Usar calculadoras**
   - Seleccionar tipo de datos en página principal
   - Ingresar valores separados por comas
   - Generar distribución y gráficos
